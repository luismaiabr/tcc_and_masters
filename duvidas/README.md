# Repositório de Dúvidas e Módulos Educacionais

[← Voltar ao Índice Principal](../README.md)

---

Este diretório armazena módulos didáticos e aprofundamentos gerados a partir de dúvidas técnicas, conceituais e estatísticas levantadas durante o desenvolvimento do TCC e a preparação para o Mestrado no IME-USP.

## Estrutura de Cada Módulo Educacional

Cada tópico de dúvida é organizado em uma pasta própria com o nome do assunto (`duvidas/<titulo_da_duvida>/`), estruturada em três arquivos canônicos:

```text
duvidas/<titulo_da_duvida>/
├── contexto.md      # Gênese da dúvida, motivação prática e inserção no qDATA/ABE
├── licao.md         # Aula/tutorial completo com rigor conceitual e aplicação em código
└── bibliografia.md  # Artigos acadêmicos, papers de mercado, blogs e livros (com capítulos)
```
